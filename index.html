Methodology & sources
  • Country/dependency area: total area (land + inland water) — Wikipedia: List of countries and dependencies by area (UN Statistics Division, FAO, CIA World Factbook)
  • Astronomical body area: spherical surface area (4πr²) — Wikipedia: List of Solar System objects by size; smaller bodies computed from mean radius (hover a row's name for a note)
  • Ocean/continent area: standard reference figures — NOAA; Wikipedia: Continent
  • Distance from Sun: each body's own Wikipedia infobox (semi-major axis); moons and all Earth features use their parent body's distance
  • Images: the CSV's image_url column is the source of truth (edit a cell to override it) — pre-filled for 256 territories via mapsicon; blank cells fall back to a live lookup via the Wikipedia REST API
